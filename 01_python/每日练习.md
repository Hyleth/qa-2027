## 为什么是"填空"而不是"从零写"

你 2021 年学过语法，问题不是"没听过"，是"手生了"。填空能让你把注意力放在
**这一行在干什么**，而不是卡在"`def` 后面要不要加冒号"这种地方。

到了 W2，你会发现自己不用再填空了——因为 `02_api` 里的代码你会反复读到。

## 先看这个：资料里查得到的 vs 查不到的（5 分钟）

廖雪峰教程讲的是**语法**，但代码里有几个写法教程里没有（`pathlib` 是后来加进标准库的，
教程没补）。下面这 5 个写法，**今天照抄就行，不需要能默写**：

```python
from pathlib import Path                          # ①

data_file = Path(__file__).parents[1] / "数据" / "cases.md"
#               ②        ③            ④

text = data_file.read_text(encoding="utf-8")      # ⑤
```

| 编号 | 写法 | 在干什么 | 大白话 |
|---|---|---|---|
| ① | `from pathlib import Path` | 把"路径"这个工具拿进来 | 作用同 `import requests` |
| ② | `__file__` | 当前这个 `.py` 文件自己的路径 | "我在哪" |
| ③ | `.parents[1]` | 往上退两级目录 | `练习/d1.py` → 退到 `01_python/` |
| ④ | `/ "数据"` | 拼路径。`Path` 把 `/` 变成了拼字符串 | 不用管 `\` 还是 `/` |
| ⑤ | `.read_text(encoding=...)` | 打开 → 全读出来 → 关掉，一行搞定 | 不用写 `open` / `close` |

**为什么要用这套**：W2 的 `02_api` 里读 YAML 用的就是第 ⑤ 句。今天抄熟了，那天就只是"见过"。

**验证你真懂了**（D1 跑通之后再做）：把 `parents[1]` 改成 `parents[0]`，再跑一遍——
看第一行打出的路径变成了什么，以及它为什么在下一行读不到文件。

**今天真正需要你理解的是这 4 个**（也就是你要填的空）：

- `.exists()` —— 文件在不在，返回 `True` / `False`
- `encoding="utf-8"` —— 用什么编码读。中文文件必须写，否则 Windows 上会乱码
- `.split("\n")` —— 按换行切成一个列表，一行一个元素
- `len(...)` —— 数一数列表里有几个

## D2 · 只挑出表格行，统计优先级

**目标**：会筛选、会数数。

新建 `练习/d2.py`：

```python
from pathlib import Path

text = (Path(__file__).parents[1] / "数据" / "cases.md").read_text(encoding="utf-8")
lines = text.split("\n")

# 只保留以 | 开头的行（表格行）
table_lines = [line for line in lines if line.startswith("____")]

# 去掉表头两行（第一行是列名，第二行是 |---|---|）
data_lines = table_lines[____:]

print("数据行数：", len(data_lines))

# 每行形如： | TC-01 | 登录 | ... |
# split("|") 之后，第 0 个是空字符串，第 1 个是编号，第 4 个是优先级
count = {}
for line in data_lines:
    cells = line.split("|")
    priority = cells[____].strip()      # 提示：优先级在第 4 列
    count[priority] = count.get(priority, 0) + ____

print("优先级统计：", count)
```

**跑出来应该是**：`数据行数：10`，`优先级统计：{'P0': 4, 'P1': 3, 'P2': 2, 'P3': 1}`

**自检**：
- 为什么 `cells[0]` 是空字符串？（因为行首有 `|`，切分后前面留了空）
- 如果某行少写了一列，`cells[4]` 会怎样？（会 IndexError —— D5 会处理这个）

## D3 · 写一个函数

**目标**：会把重复代码抽成函数。

新建 `练习/d3.py`：

```python
from pathlib import Path


def load_cases():
    """读出所有用例行，返回一个列表，每个元素是 dict。"""
    text = (Path(__file__).parents[1] / "数据" / "cases.md").read_text(encoding="utf-8")
    rows = [l for l in text.split("\n") if l.startswith("|")][2:]

    cases = []
    for row in rows:
        cells = [c.strip() for c in row.split("|")]
        # cells: ['', 'TC-01', '登录', '正确账号密码可以登录', 'P0', '跳转到首页...', '']
        cases.append({
            "id": cells[____],
            "module": cells[2],
            "title": cells[3],
            "priority": cells[____],
            "expected": cells[5],
        })
    return cases


cases = load_cases()
print(f"共 {len(cases)} 条用例")

# 列表推导式：挑出所有 P0
p0 = [c["title"] for c in cases if c["priority"] == "____"]
print(f"P0 有 {len(p0)} 条：")
for t in p0:
    print("  -", t)
```

**跑出来应该是**：`共 10 条用例`，`P0 有 4 条`，下面列出 4 个标题。

**自检**：
- 把 `def load_cases():` 改成 `def load_cases(priority=None):`，让它能筛选任意优先级 —— 这就是"参数化"的最原始形态。

## D5 · 别让程序崩在第一行

**目标**：能处理"文件不存在""字段缺失"这类情况。

新建 `练习/d5.py`：

```python
from pathlib import Path


def read_case_count(path):
    """读文件里的用例条数。文件不存在时返回 0，不要崩。"""
    try:
        text = Path(path).read_text(encoding="utf-8")
        return len([l for l in text.split("\n") if l.startswith("|")]) - 2
    except ____:                 # 提示：文件不存在是哪种异常？
        print(f"没找到文件：{path}")
        return ____


def get_priority(case, index=4):
    """安全地取某一列。列不存在时返回 'UNKNOWN'。"""
    cells = case.split("|")
    try:
        return cells[index].strip()
    except ____:                 # 提示：下标越界是哪种异常？
        return "UNKNOWN"


if __name__ == "__main__":
    base = Path(__file__).parents[1] / "数据"

    print("正常文件：", read_case_count(base / "cases.md"))       # 期望 10
    print("不存在的文件：", read_case_count(base / "no_such.md"))  # 期望 0，且不崩

    bad_line = "| TC-99 | 登录 |"
    print("缺列的行：", get_priority(bad_line))                    # 期望 UNKNOWN
```

**跑出来应该是**：`10`、`没找到文件...` + `0`、`缺列的行：UNKNOWN`

**自检**：
- 为什么测试代码里到处是 `try/except`，而业务代码里不该随便 `except: pass`？
  （提示：吞掉异常等于隐藏缺陷。测试代码吞异常是为了"继续跑完剩下的用例"）

## 做不出来怎么办

| 卡在哪 | 怎么办 |
|---|---|
| 不知道 `____` 填什么 | 把上一行的变量名念一遍，问"我现在手上有什么、下一步要什么" |
| 报 `IndentationError` | 缩进不一致。Python 用 4 个空格，不要混 Tab |
| 报 `KeyError` / `IndexError` | 打印 `cells` 或 `dict` 出来看结构，别猜 |
| 报中文乱码 | `encoding="utf-8"` 漏了 |
| 卡超过 30 分钟 | **直接问我**，别硬扛。W1 的目标是"手熟"，不是"受虐" |

最后一句：**这六个练习加起来不超过 100 行代码，但它们的结构和你 W2 要读的框架是同一套。**
现在填的每一个空，都是为了让 W2 那天你能看懂别人的代码，而不是又一次"抄完就忘"。
