## 一、`split(分隔符)` —— 把字符串切成列表

**干什么**：按指定字符把一个字符串切开，得到一个列表。

```python
"a,b,c".split(",")        # ['a', 'b', 'c']
"hello world".split()     # ['hello', 'world']   ← 不写参数：按任意空白切
"| TC-01 | 登录 |".split("|")   # ['', ' TC-01 ', ' 登录 ', '']   ← 注意首尾是空串
```

**坑 1：首尾的分隔符会产生空字符串**

```python
"|abc|".split("|")   # ['', 'abc', '']
#                      ↑ 行首有 |，前面什么都没有，所以是 ''
```

**坑 2：文件末尾的换行会多切出一个空串**

```python
"a\nb\n".split("\n")   # ['a', 'b', '']   ← 最后那个 '' 是"幽灵行"
```

这就是为什么 D1 数行数是 18 而不是 17。

**参数 `maxsplit`**：最多切几次。`"a|b|c".split("|", 1)` → `['a', 'b|c']`。

---

## 二、`splitlines()` —— 按行切

**干什么**：按行边界切，**不会产生末尾的幽灵空串**。

```python
"a\nb\n".splitlines()   # ['a', 'b']   ← 对比 split("\n") 的 ['a','b','']
```

**什么时候用哪个**：数行数、按行处理文本 → `splitlines()`；
按自定义分隔符（如 `|`、`,`）切 → 只能 `split()`。

## 三、`startswith()` / `endswith()` —— 判断开头/结尾

**干什么**：返回 `True` / `False`。

```python
"| TC-01 |".startswith("|")   # True
"TC-01 |".startswith("|")     # False
"report.html".endswith(".html")  # True
```

**易混**：`startswith` 是"必须长在开头"，和 `in` 不同：

```python
"|" in "TC-01 | 登录"          # True   ← 在中间也算
"TC-01 | 登录".startswith("|")  # False  ← 开头是 T，不是 |
```

**参数**：括号里可以是任意长度的字符串，甚至可以是元组（多个候选）：

```python
"abc".startswith(("a", "b"))   # True   ← 满足任意一个就 True
```

## 四、`strip()` —— 去首尾空白

**干什么**：去掉字符串**两端**的空格、换行、Tab。中间的不动。

```python
"  hello  ".strip()    # 'hello'
"  TC-01 \n".strip()   # 'TC-01'
"a b c".strip()        # 'a b c'   ← 中间空格不动
```

**变体**：`lstrip()` 只去左边，`rstrip()` 只去右边。

**D2 为什么用它**：表格行被 `split("|")` 切开后，每个格子长这样 `' TC-01 '`（两边有空格），
`cells[4].strip()` 才是干净的 `'P0'`。

## 五、`dict.get(键, 默认值)` —— 安全取值

**干什么**：从字典里取值；key 不存在时**返回默认值，不报错**。

```python
count = {"P0": 4}
count["P0"]           # 4
count["P9"]           # 报 KeyError！
count.get("P9")       # None（不报错）
count.get("P9", 0)    # 0（给了默认值）
```

**D2 为什么用它**：`count.get(priority, 0) + 1` 的意思是
"这个优先级之前出现过就取出次数，没出现过就当 0，再加 1"。

## 六、`list[起始:结束]` —— 切片

**干什么**：从列表里取一段。**含头不含尾**。

```python
lines = ["表头", "分隔线", "TC-01", "TC-02"]
lines[2:]     # ['TC-01', 'TC-02']   ← 从下标 2 到结尾
lines[:2]     # ['表头', '分隔线']   ← 从开头到下标 2 之前
lines[-1]     # 'TC-02'            ← 负数：倒数第 1 个
```

**D2 为什么用 `[2:]`**：表格前两行是"列名"和"分隔线"，不是数据，跳过它们。

## 七、其他 W1 会碰到的内置函数

| 函数 | 干什么 | 例子 |
|---|---|---|
| `len(x)` | 数长度 | `len([1,2,3])` → `3`；`len("abc")` → `3` |
| `sum(x)` | 求和 | `sum([1,2,3])` → `6` |
| `float(x)` | 转小数 | `float("199.00")` → `199.0` |
| `int(x)` | 转整数 | `int("5")` → `5` |
| `sorted(x)` | 排序 | `sorted([3,1,2])` → `[1,2,3]` |
| `str(x)` | 转字符串 | `str(5)` → `'5'` |

**算钱不要用 `float`**：`0.1 + 0.2` 不等于 `0.3`。真实项目用 `Decimal`（W3 再学）。
