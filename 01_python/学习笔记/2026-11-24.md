## 二、SQLite 是什么、怎么用

### 是什么

一个"单文件数据库"：不用装、不用启动服务、不用账号密码，整个数据库就是一个文件（`test.db`）。
Python 自带 `sqlite3` 模块，一行都不用装。练 SQL 就用它，语句和 MySQL 几乎一样。

### 三步用法

```python
import sqlite3

conn = sqlite3.connect("test.db")   # ① 打开/新建数据库文件
cur = conn.cursor()                 # ② 拿"游标"，执行 SQL 的手
cur.execute("SQL语句")             # ③ 执行 SQL
conn.commit()                       # 提交，数据才写进文件
cur.fetchall()                      # 取出查询结果
conn.close()
```

### 关键点

- `IF NOT EXISTS`：建表时带上，表已存在就不会报错
- `DELETE FROM 表`：清空表，防止重复跑时数据翻倍
- `conn.commit()`：**不提交数据等于白插**
- `REAL`：金额用的小数类型（练语法用这个就行）

## 三、JOIN（拼接两张表）

### 是什么

把两张表按某个关联字段拼起来。订单表只存 `user_id`（数字），要看人名得 JOIN 用户表。

### 语法

```sql
SELECT 表A.列, 表B.列
FROM 表A
JOIN 表B ON 表A.某列 = 表B.某列
```

- `FROM`：从哪张表出发
- `JOIN`：接哪张表
- `ON`：拼接规则（等号成立才配成一行）

### 自己写的（改对了一个拼写错 FORM→FROM）

```python
print("订单+人名:", cur.execute(
    "SELECT ORDERS.ID, USERS.NAME FROM USERS JOIN ORDERS ON USERS.ID = ORDERS.USER_ID"
).fetchall())
# [(1, '张三'), (2, '张三'), (3, '李四'), (4, '王五')]
```

### 要点

- JOIN 是逐行配对的，一对多就会重复（张三两笔单 → 出现两次）
- 两张表同名的列（都叫 id）必须带表名前缀，写 `users.id` 不能光写 `id`
- 默认是"内连接"：配不上对的行会被丢掉

## 四、GROUP BY + 聚合函数（分组统计）

### 是什么

把"某列值相同"的行归成一组、压成一行，配聚合函数算统计。分组是骨架，聚合是血肉。

### 聚合函数

| 函数 | 干什么 |
|---|---|
| `COUNT(*)` | 数这一组有几行 |
| `SUM(列)` | 把这一列加起来 |

`AVG()`（平均）、`MAX/MIN()`（最大最小）用法一样。

### 语法

```sql
SELECT 分组列, 聚合函数
FROM 表
GROUP BY 分组列
```

### 自己写的

```python
print("每人订单数:", cur.execute(
    "select u.name, count(*) from users u join orders o on u.id = o.user_id group by u.name"
).fetchall())
# [('张三', 2), ('李四', 1), ('王五', 1)]
```

### 铁律（必须记住）

`SELECT` 里的列，**要么在 `GROUP BY` 里，要么被聚合函数包着**，不能有"裸列"。

## 五、HAVING（分组后过滤，今天的合格线）

### 是什么

分组**之后**再筛选。`WHERE` 在分组**前**过滤原始行，`HAVING` 在分组**后**过滤聚合结果。

### 为什么"总金额>100"不能用 WHERE

总金额是 `SUM()` 算完才有的数字，原始每一行里根本没有，所以 WHERE 算不了，只能 HAVING。

### 自己写的（合格线）

```python
print("总金额>100的用户:", cur.execute(
    "select u.name, sum(o.amount) from users u "
    "join orders o on u.id = o.user_id group by u.name having sum(o.amount) > 100"
).fetchall())
# [('张三', 230.0), ('李四', 200.0)]
```

这条同时用上 JOIN + GROUP BY + SUM + HAVING，是今天全部内容的合体。

## 六、表别名（自己冒出来的进阶写法）

`FROM users u` 就是给表起别名 `u`，之后全程用 `u` 代替 `users`。只在这一句里有效，起了别名后原表名不能再用。

## 七、Linux 三命令（只记用途，不用跑）

| 命令 | 是什么 | 最常用 | 测试场景 |
|---|---|---|---|
| `grep` | 搜关键词挑出行 | `grep "ERROR" app.log` | 日志里找报错行 |
| `tail -f` | 追文件末尾实时打印 | `tail -f app.log` | 起服务时盯日志 |
| `awk` | 按分隔符拆列取某列 | `awk -F'\|' '{print $2}'` | 只提日志某列 |

口诀：grep 找行、tail -f 追尾巴、awk 拆列。
