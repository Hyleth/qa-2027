## 一、这段代码在干什么

有一堆字典（比如一批测试用例、一批接口请求参数），想知道：
- 每个 **字段名（key）** 出现了几次
- 每个 **字段值（value）** 出现了几次

```python
items = [
    {"name": "张三", "age": 20},
    {"name": "李四", "age": 20},
    {"name": "张三"}          # 注意：这条没有 age
]

k_sum = {}
v_sum = {}
for i in items:
    for k in i.keys():
        k_sum[k] = k_sum.get(k, 0) + 1      # 统计每个 key 出现几次
    for v in i.values():
        v_sum[v] = v_sum.get(v, 0) + 1      # 统计每个 value 出现几次

print(k_sum)   # {'name': 3, 'age': 2}
print(v_sum)   # {'张三': 2, '李四': 1, 20: 2}
```

---

## 二、运行结果

```
{'name': 3, 'age': 2}
{'张三': 2, '李四': 1, 20: 2}
```

- `name` 三条都有 → 3 次；`age` 只有前两条有 → 2 次
- 值 `张三` 出现了 2 次、`李四` 1 次、`20` 2 次

---

## 三、两个必须记住的点

### 1. `d.get(k, 0) + 1` 是「计数器」的标准写法

- `d.get(k, 0)`：key 存在就取它的值，不存在就当作 0
- `+ 1`：这次又见到它，加一次
- 不能直接写 `d[k] = d[k] + 1`，因为第一次见到 `k` 时字典里还没有它，会报 `KeyError`

### 2. `Counter()` 是同样的东西，但更省事

```python
from collections import Counter

c1 = Counter([k for i in items for k in i.keys()])
c2 = Counter([v for i in items for v in i.values()])

print(dict(c1))   # {'name': 3, 'age': 2}
print(dict(c2))   # {'张三': 2, '李四': 1, 20: 2}
```

- `Counter(列表)` 直接帮你数好每个元素出现几次
- 它返回的是 `Counter` 对象，打印出来像字典；想当成普通字典用时，用 `dict()` 转一下

---

## 四、易错点（复盘重点）

| 坑 | 说明 |
|---|---|
| 大小写 | 统计前如果值里有 `"P0"` 和 `"p0"`，会当成两个不同的值。所以数据里的枚举值要统一大小写 |
| `dict()` 转换 | `Counter` 对象不是普通 `dict`，要 `dict(c)` 转一下才是标准字典 |
| 缺字段的字典 | 上面第 3 条 `{"name": "张三"}` 没有 `age`，所以 `age` 只出现 2 次——统计会如实反映「哪些字段不全」，这本身是有用信息 |

---

## 五、它和你工作的关系

- 统计**字段出现次数** = 检查一批接口响应里，是不是有的字段不是每个返回都有（字段缺失）
- 统计**值出现次数** = 数用例优先级分布（`P0` 几条、`P1` 几条），就是 D2 那个 `count.get(priority, 0) + 1` 的推广
- `Counter` 是 Python 里做「频次统计」最快的写法，读别人代码时会常见到

## 六、只统计「某一个 key」的值（进阶：先收集再统计）

上一节是统计**所有** key、所有 value。但更常见的需求是：**只想统计某一个字段的值分布**，比如只想数 `name` 里「张三」出现几次。

```python
from collections import Counter

items = [
    {"name": "张三", "age": 20, "sex": "man"},
    {"name": "李四", "age": 20, "sex": "man"},
    {"name": "张三", "sex": "woman"}       # 这条没有 age
]

# 写法一：先收集 name 到一个列表，再统计
n = []
for i in items:
    n.append(i["name"])
print(n)          # ['张三', '李四', '张三']

n_sum = {}
for s in n:
    n_sum[s] = n_sum.get(s, 0) + 1
print(n_sum)      # {'张三': 2, '李四': 1}

# 写法二：一行搞定
c = Counter([i["name"] for i in items])
print(dict(c))    # {'张三': 2, '李四': 1}
```

运行结果：

```
['张三', '李四', '张三']
{'张三': 2, '李四': 1}
{'张三': 2, '李四': 1}
```

**关键点**：
- `i["name"]` 是「从字典里取出某一个 key 的值」，和上一节 `i.keys()` / `i.values()`（取所有 key / 所有 value）不同
- 写法一里那个「先建空列表 `n`，循环 `append`，再统计」的**三步套路**，和 `Counter` 那行是同一件事——列表推导式 `[i["name"] for i in items]` 就是 `n.append` 循环的一行版
- 这条代码里的 `sex` 字段没参与统计，因为根本没取它——说明「统计哪个字段」完全由你 `i["xxx"]` 里写哪个决定

## 七、对照参考（今天所有写法的关系）

| 要统计什么 | 普通写法（get 计数器） | Counter 简写 |
|---|---|---|
| 所有 key 出现几次 | `for k in i.keys(): k_sum[k] = k_sum.get(k,0)+1` | `Counter([k for i in items for k in i.keys()])` |
| 所有 value 出现几次 | `for v in i.values(): v_sum[v] = v_sum.get(v,0)+1` | `Counter([v for i in items for v in i.values()])` |
| 某一个 key 的值（如 name） | 先 `n.append(i["name"])` 收集，再 `get` 计数 | `Counter([i["name"] for i in items])` |

**一句话记住它们的区别**：

- `i.keys()` / `i.values()` = 取**整本字典**的所有键 / 所有值
- `i["name"]` = 只取**一个**叫 `name` 的键的值

三个场景在测试里分别对应：查「字段全不全」、查「所有值分布」、查「某个字段（比如优先级、状态码）的分布」。
