> 主题：**统计「key 出现次数」和「value 出现次数」**，以及用 `Counter()` 的简写

---

## 一、这段代码在干什么

有一堆字典（比如一批测试用例、一批接口请求参数），想知道：
- 每个 **字段名（key）** 出现了几次
- 每个 **字段值（value）** 出现了几次

```python
items = [
    {"name": "张三", "age": 20},
    {"name": "李四", "age": 20},
    {"name": "张三"}          # 注意：这条没有 age
]

k_sum = {}
v_sum = {}
for i in items:
    for k in i.keys():
        k_sum[k] = k_sum.get(k, 0) + 1      # 统计每个 key 出现几次
    for v in i.values():
        v_sum[v] = v_sum.get(v, 0) + 1      # 统计每个 value 出现几次

print(k_sum)   # {'name': 3, 'age': 2}
print(v_sum)   # {'张三': 2, '李四': 1, 20: 2}
```

---

## 二、运行结果

```
{'name': 3, 'age': 2}
{'张三': 2, '李四': 1, 20: 2}
```

- `name` 三条都有 → 3 次；`age` 只有前两条有 → 2 次
- 值 `张三` 出现了 2 次、`李四` 1 次、`20` 2 次

---

## 三、两个必须记住的点

### 1. `d.get(k, 0) + 1` 是「计数器」的标准写法

- `d.get(k, 0)`：key 存在就取它的值，不存在就当作 0
- `+ 1`：这次又见到它，加一次
- 不能直接写 `d[k] = d[k] + 1`，因为第一次见到 `k` 时字典里还没有它，会报 `KeyError`

### 2. `Counter()` 是同样的东西，但更省事

```python
from collections import Counter

c1 = Counter([k for i in items for k in i.keys()])
c2 = Counter([v for i in items for v in i.values()])

print(dict(c1))   # {'name': 3, 'age': 2}
print(dict(c2))   # {'张三': 2, '李四': 1, 20: 2}
```

- `Counter(列表)` 直接帮你数好每个元素出现几次
- 它返回的是 `Counter` 对象，打印出来像字典；想当成普通字典用时，用 `dict()` 转一下

---

## 四、易错点（复盘重点）

| 坑 | 说明 |
|---|---|
| 大小写 | 统计前如果值里有 `"P0"` 和 `"p0"`，会当成两个不同的值。所以数据里的枚举值要统一大小写 |
| `dict()` 转换 | `Counter` 对象不是普通 `dict`，要 `dict(c)` 转一下才是标准字典 |
| 缺字段的字典 | 上面第 3 条 `{"name": "张三"}` 没有 `age`，所以 `age` 只出现 2 次——统计会如实反映「哪些字段不全」，这本身是有用信息 |

---

## 五、它和你工作的关系

- 统计**字段出现次数** = 检查一批接口响应里，是不是有的字段不是每个返回都有（字段缺失）
- 统计**值出现次数** = 数用例优先级分布（`P0` 几条、`P1` 几条），就是 D2 那个 `count.get(priority, 0) + 1` 的推广
- `Counter` 是 Python 里做「频次统计」最快的写法，读别人代码时会常见到
