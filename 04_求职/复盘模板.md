# 面试复盘模板（每场面试后 24 小时内填，10 分钟）

> **规则：一场面试只带走一个改进项，其余全忘掉。**
> 一次改十个等于一个都没改，还会让你下一场更紧张。

---

## 基本信息

```
日期：____　　公司：____　　岗位：____　　渠道：BOSS / 猎聘 / 内推 / 官网
面试轮次：HR 初筛 / 技术一面 / 技术二面 / 主管面 / HR 终面
结果：待定 / 进入下一轮 / 已挂
```

---

## 二、砸在哪（只写最疼的那一个）

```
我问的是：____
我答的是：____
正确/更好的答法：____
根因：□ 没做过  □ 做过但讲不清  □ 听错了问题  □ 紧张
```

---

## 三、对方的反应（这些信号比你的感觉准）

- 有没有追问？追问了几层？（追问 3 层以上 = 感兴趣，或不信任）
- 有没有主动介绍团队 / 项目？（有 = 想要你）
- 有没有问「你还有什么问题」之后聊很久？（聊得久 = 加分）
- 有没有提薪资范围？（提了 = 进入实质阶段）

---

| 缺口 | 属于哪一类 | 要不要补 |
|---|---|---|
| | AI 测试 / 接口自动化 / 传统测试 / 表达 | 补 / 不补（不补的写明理由） |

**只挑一个标"本周补"。** 其余的记下来，等 W16 集中处理。

## 五、下一场要改的一件事

```
这一件事：____
怎么练：____（例如：把「RAG 召回率怎么算」写成 90 秒稿，念 5 遍）
什么时候验：下一场面试
```

## 附：四类问题的高频清单（面完打勾）

**AI 测试类**
- [ ] 给你一个 AI 客服机器人，你怎么测
- [ ] 幻觉怎么测，怎么判断是检索错还是生成错
- [ ] 怎么证明模型 v2 比 v1 好
- [ ] 评测集怎么建，多少条够
- [ ] LLM-as-a-Judge 有什么问题
- [ ] Prompt 注入怎么测
- [ ] RAG 召回率怎么算

**接口自动化类**
- [ ] fixture 四种作用域，什么时候用 session
- [ ] 为什么不能只断言 status_code
- [ ] 用例之间有依赖怎么办
- [ ] 数据驱动 Excel 和 YAML 选哪个

**传统测试类**
- [ ] 一个需求给你怎么设计用例
- [ ] 缺陷怎么定级，P0 和 P1 的界线
- [ ] 线上事故怎么复盘
- [ ] 上线卡点怎么定

**个人类**
- [ ] 为什么空窗一年
- [ ] 为什么想做 AI 测试
- [ ] 9 年经验为什么只要 15K
- [ ] 年龄比团队都大，能接受被年轻人带吗
