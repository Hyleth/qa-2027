# 学习资料清单（2026-11 版）

> 每个知识点：**在哪学 / 看哪一部分 / 看多久 / 看不看视频**。
> 链接打不开就搜「站点名 + 章节名」，别在找资料上花时间。
> **本文档最重要的一节是最后「不要看的东西」**——省下来的时间比学到的时间更值钱。

---

## 一、总原则

1. **每个知识点只给 1 个主资料 + 最多 1 个备选。** 找三个教程对比，是最常见的自我欺骗。
2. **官方文档优先于博客。** 博客经常是 2019 年的、代码跑不通；官方文档永远跟版本。
3. **看的时间 : 写的时间 ≤ 3 : 7。** 你 2021 年那次失败，大概率是"看完了觉得会了"。
4. **视频只在"完全没概念"时看。** 有概念了就回归文字 + 动手。

## 五、Playwright（W4 三个半天）

| 项 | 内容 |
|---|---|
| **主资料** | 官方文档 · <https://playwright.dev/python/docs/intro> |
| **看哪三页** | ① Getting Started ② Locators ③ Assertions |
| **看多久** | 累计 1.5 小时（每天 30 分钟） |
| **不要看** | API 大全（几百个方法）、Trace Viewer、网络拦截、移动端模拟、组件测试 |

**三页各自的重点**：

| 页面 | 你只要拿走这一件事 |
|---|---|
| Getting Started | 怎么起浏览器、打开页面、点元素、截图（10 行代码） |
| Locators | `get_by_role()` / `get_by_test_id()` / `get_by_text()` 三个就够；**永远别用 xpath 绝对路径** |
| Assertions | `expect(locator).to_be_visible()` 这类会自动重试，**所以不用写 sleep** |

**视频**：B 站搜「Playwright Python 入门」，看 1 集（30 分钟内）建立直观印象即可。

**POM 是什么**：不用专门找资料。W4 周五那天你会自己写一个 `LoginPage` 类，写完就懂了——**POM 就是"每个页面一个类"这么简单的一件事**，被博客讲复杂了。

## 八、AI 概念（W5–W10，最重要）

### 8.1 你的主资料是本地文件

**`04_AI零基础手册.md`** —— 这是专门为你写的，21 章，分三部分：

| 部分 | 章节 | 内容 |
|---|---|---|
| 原理 | 1–10 | 生成机制、token、请求链路、Prompt、结构化输出、幻觉、Embedding、RAG、Agent、技术选型 |
| 方法 | 11–19 | 八层测试地图、预期结果问题、评测集设计、指标体系、判定器校准、非确定性处理、安全测试、性能成本、线上闭环 |
| 速查 | 20–21 | 名词表（含英文）、25 道自测题 |

每章结构是：**一句话导语（这章讲什么）→ 定义 → 这在测试上意味着什么 → 检查点**。**先看它，看不懂的再去外面查。**

第 12–15 章（预期结果问题 / 评测集 / 指标 / 判定器）是全手册最核心的部分，也是 AI 测试岗与传统测试岗能力差异的实际落点，W6–W7 会用到。

### 8.3 视频：什么时候值得看

| 情况 | 看不看 |
|---|---|
| 完全没概念，看文字发怵 | 看 1 集（30 分钟内），建立印象就关 |
| 有概念了，想深入 | 不看。看书/文档 + 动手 |

## 十一、**不要看的东西**（这一节最重要）

下面每一项都能吃掉你 3 天以上，而且对目标岗位没用。**看到就划走。**

| 不要碰 | 为什么 |
|---|---|
| ❌ Python 装饰器原理、生成器、`asyncio`、元类 | 你只需要认识 `@pytest.fixture` 这个标签。原理是面试造火箭才问的 |
| ❌ Django / Flask / FastAPI 教程 | 你是测试不是开发，不需要写 Web 服务 |
| ❌ 机器学习 / 深度学习 / 神经网络数学 | 测试岗不问反向传播。想了解就看 3Blue1Brown 一集视频，够了 |
| ❌ 从头训练/微调模型 | 那是算法岗的活。你只要会"用"和"测" |
| ❌ K8s / 服务网格 / 云原生全家桶 | 测试岗极少要求，学了也没场景练 |
| ❌ 刷 LeetCode | 测试岗手撕代码的比例很低，性价比最差 |
| ❌ 前端框架（Vue/React） | 除非要写测试平台，否则用不上 |
| ❌ "AI 测试平台" 自研教程 | 中小公司不看，大厂要真项目 |
| ❌ 各种"大模型从零到一"长视频 | 2 小时起，看完什么都留不下 |
| ❌ 找"最好的教程" | 这是拖延的高级形式。随便选一个开始写代码 |

## 十二、一张表总结：整个计划你要读多少

| 类别 | 累计阅读时间 | 占比 |
|---|---|---|
| Python | 2 h | 3% |
| pytest + 接口 + HTTP | 4 h | 6% |
| Playwright | 1.5 h | 2% |
| Git + Actions + Docker | 2 h | 3% |
| SQL + Linux | 1 h | 1.5% |
| AI 概念（含本地手册） | 8 h | 12% |
| AI 评测 | 6 h | 9% |
| **阅读合计** | **≈ 25 h** | **37%** |
| **动手（写代码、跑实验、改 bug）** | **≈ 43 h** | **63%** |

**这个比例是刻意的。** 你 2021 年那次的问题不是读得少，是读得太多、写得太少。
